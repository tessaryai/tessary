# Tessary content guide

This guide defines how Tessary communicates across the company, product, documentation, and marketing.

## Start here

Read these guides in order:

1. [Brand foundations](brand-foundations.md) defines who Tessary is, who we write for, what we want people to believe, and what makes Tessary different.
2. [Voice and tone](voice-and-tone.md) defines how Tessary sounds and how that voice adjusts to the situation.
3. [Writing style guide](writing-style-guide.md) contains the language and formatting rules that apply everywhere.

Then use the guide for your context:

- [Product copy guide](product-copy-guide.md) for interface text, actions, states, errors, warnings, and product-generated results
- [Documentation style guide](documentation-style-guide.md) for tutorials, explanations, how-to guides, and reference documentation
- [Marketing copy guide](marketing-copy-guide.md) for the website, announcements, social media, emails, comparisons, and customer stories
- [Product glossary](product-glossary.md) for canonical product terms and definitions

## Which rules take priority

Apply guidance in this order:

1. Context-specific guide
2. Tessary writing style guide
3. Tessary voice and tone
4. Tessary brand foundations

The product glossary is authoritative whenever a Tessary term is used.

Use judgment when a rule does not fit the context. Clarity, accuracy, and trust take priority over mechanical consistency.

## Keep the guide current

Treat these documents as a living system. Add or change a rule when repeated decisions reveal that guidance is missing, unclear, or no longer reflects Tessary.

Prefer principles and reusable patterns over rules tied to one feature or moment in the product.
